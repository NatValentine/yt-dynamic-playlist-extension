# Dynamic Youtube Playlist Extension

This is a Firefox extension that allows users to create a Youtube playlist from open tabs.

## Motivation
I'm in the habit of going through my subscriptions feed and opening videos that look interesting in new tabs. I usually have some of them playing in the background while I do other things. The intention with this extension is to avoid having to stop what I'm doing and manually switch from un video to another when the current one ends.

## Features
- Detect open YouTube tabs
- Show title, channel, duration
- Highlight currently playing tab
- Auto-switch to next video when one ends
- Auto-play next video
- Toggle ON/OFF from popup

## Tech Stack
- JavaScript
- Firefox WebExtensions API
- HTML/CSS

## Installation
Load temporarily via about:debugging
